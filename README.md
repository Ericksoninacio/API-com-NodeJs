# API com Node.js

API REST desenvolvida em Node.js com Express.

## Sobre
API backend completa com autenticação JWT, CRUD, validações e documentação Swagger.

## Tecnologias
- **Node.js**
- **Express**
- **SQLite3**
- **JWT** (autenticação)
- **Swagger** (documentação)
- **JavaScript**

## Funcionalidades
- Autenticação com JWT
- Rotas organizadas (MVC + Services)
- Validações
- Documentação interativa (Swagger)

## Como rodar

```bash
# Clone o repositório
git clone https://github.com/Ericksoninacio/API-com-NodeJs.git

# Entre na pasta
cd API-com-NodeJs

# Instale as dependências
npm install

# Rode a API
npm start
